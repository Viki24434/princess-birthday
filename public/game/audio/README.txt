Audio untuk Petualangan Menuju Kastil
===================================

Musik latar: background.mp3
Happy Adventure (Loop) oleh TinyWorlds
Sumber: https://opengameart.org/content/happy-adventure-loop
File asli: happy_adveture.mp3
Lisensi: CC0 1.0 (public domain).

Efek suara: WAV dari Juhani Junkala (SubspaceAudio)
Koleksi: The Essential Retro Video Game Sound Effects Collection [512 sounds]
Sumber: https://opengameart.org/content/512-sound-effects-8-bit-style
Lisensi: CC0 1.0 (public domain), dinyatakan juga dalam INFO.txt paket asli.

Pemetaan file (disalin tanpa mengubah isi audio):
jump.wav       <- sfx_movement_jump1.wav
heart.wav      <- sfx_coin_double1.wav

Lisensi CC0: https://creativecommons.org/publicdomain/zero/1.0/

Mengganti audio:
Letakkan file pengganti di folder ini. Jika nama dan formatnya sama,
cukup timpa file tersebut. Jika memakai nama/format berbeda (MP3/WAV/OGG),
ubah properti file di MUSIC atau SOUNDS pada src/game/audio/gameAudio.js.
Volume masing-masing audio juga diatur di sana (0 sampai 1).
Pakai audio yang hak penggunaannya sudah kamu miliki.
