Ornamen PNG photobooth — Microsoft Fluent Emoji
================================================

Kelima PNG di folder ini diunduh langsung dari repositori resmi
Microsoft Fluent Emoji dan menggantikan aset hasil generasi AI sebelumnya.

Sumber: https://github.com/microsoft/fluentui-emoji
Pembuat: Microsoft Corporation.
Lisensi: MIT. Teks lisensi asli disertakan di LICENSE-MICROSOFT.txt.
Commit sumber: 1ffb34c752ecf5d402f04cfb4b392c77f57c54bc

Pemetaan file lokal:
bow.png     <- assets/Ribbon/3D/ribbon_3d.png
sparkle.png <- assets/Sparkles/3D/sparkles_3d.png
cake.png    <- assets/Birthday cake/3D/birthday_cake_3d.png
gift.png    <- assets/Wrapped gift/3D/wrapped_gift_3d.png
flower.png  <- assets/Cherry blossom/3D/cherry_blossom_3d.png

File PNG asli disalin tanpa perubahan gambar dan hanya diberi nama lokal.
Masing-masing berukuran 256 x 256 piksel dengan latar transparan.
URL unduhan lengkap dan SHA-256 tiap file tercatat di sources.json.

Dipakai untuk pratinjau kamera dan hasil unduhan 1, 3, serta 4 foto.
